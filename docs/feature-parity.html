Not in any plan yet — the punch list

Everything below exists on desktop (or was flagged during reviews) and is currently in no committed Android plan. My recommended destination for each:

  1. Last.fm scrobbling — own task batch; desktop module ports cleanly
  2. Favorites sync back to Tidal — bundle with the Collection merge in the parity milestone
  3. Crossfade — real engineering (second player instance); schedule after the DSP suite
  4. Rich local metadata enrichment — fixes undersold FLAC quality badges; small background pass
  5. Theme toggle + source priority + About — all belong in the Settings screen (parity milestone); listing so they don't get lost
  6. Smart playlists — biggest gap; needs schema + rules engine + UI, its own milestone
  7. Credits / Properties actions + card long-press menus — bundle into the parity milestone's context-menu completion
  8. Scroll-position persistence — was a P1 on desktop; add to the M3b.1 polish pass
  9. Spectrum visualizer — blocked on a Media3 audio tap; revisit only if a clean approach appears

Where Android is ahead of desktop

  • AutoEq picker — searchable 8,850-profile database, offline; desktop only imports files
  • Expiring-URL self-healing — Tidal streams auto-refresh mid-queue
  • Playback resumption — queue restores into the media notification after process death
  • Playback error banner — failures are visible, not silent
  • Coming in the DSP suite — bass boost, channel balance, limiter, reverb, virtualizer (each individually toggleable)
  • Original mobile roadmap — Android Auto, Chromecast, widgets, offline downloads, per-device Bluetooth EQ profiles
